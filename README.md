# Computer Science And Neural Networks In Minecraft

A non-academic repo where concepts of CS are explained through [redstone](https://minecraft.fandom.com/wiki/Tutorials/Redstone) in [Minecraft](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-2) (1.26.2).

## What this project is about

I don't wanna brag about myself, but I will also be implementing [TCP](https://www.ietf.org/archive/id/draft-ietf-tcpm-rfc793bis-25.html) architecture by sending signals and storing them.

A simplest form of neural network will also be implemented, like some sort of classifier (such as a [Perceptron](https://perceptronscan.com/docs.html)) — however, the weights will be manually inputted.

This will be made purely using redstone dust and other helper blocks, except [command blocks](https://minecraft.fandom.com/wiki/Command_Block).

## Storage

To store those signals using TCP, and the weights themselves, a storage system will also be made using blocks such as [barrels](https://minecraft.fandom.com/wiki/Barrel).
